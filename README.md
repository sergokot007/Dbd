# DBD Fog Companion — Web
Неофициальный веб-спутник Dead by Daylight для телефона и компьютера.

## Публикация
GitHub Actions публикует сайт при каждом push в main. Адрес после успешного деплоя:
https://sergokot007.github.io/Dbd/

Если GitHub Pages ещё не включён, открой Settings → Pages и выбери Source: GitHub Actions.

## Возможности
- Персонажи, перки, предметы и карты из API.
- Поиск, фильтры и избранное (сохраняется в браузере).
- Установка на главный экран (PWA), кэш интерфейса.
Данные загружаются из стороннего API dbd.tricky.lol; его доступность не контролируется проектом.
