# Портреты персонажей

Локальные WebP-портреты для владельцев перков сохранены из `public/characters/` репозитория [flexeykinDev/dbd-perk-randomizer](https://github.com/flexeykinDev/dbd-perk-randomizer).

Исходный репозиторий распространяется по лицензии MIT; текст лицензии лежит в `data/LICENSE-MIT.txt`, атрибуция локализации — в `data/CREDITS.md`. Персонажи и изображения Dead by Daylight принадлежат Behaviour Interactive и её лицензиарам. Портреты используются в неофициальном справочнике и загружаются локально, без обращения к GitHub во время работы сайта.
